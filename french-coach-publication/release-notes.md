# French Coach 1.0.0 — draft release notes

Initial public release of French Coach, a skills-only plugin for practical French learning and writing support.

Highlights:

- Concise correction of meaningful grammar and vocabulary errors.
- Clear separation between required corrections and optional style improvements.
- Natural English-to-French and Spanish-to-French translation.
- Conversational practice that keeps exchanges moving.
- Targeted explanations, exercises, and review of recurring patterns.
- Register-aware feedback that preserves the learner's intended meaning and tone.
- Explicit educational limits for proficiency certification and high-stakes wording.

This release does not include connectors, an MCP server, authentication, or developer-operated data collection.
